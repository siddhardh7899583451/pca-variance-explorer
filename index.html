Beginner’s Guide to PCA

What is dimensionality reduction?

Many real-world datasets have dozens or hundreds of features. Dimensionality reduction finds a lower-dimensional representation that still captures the essential structure, making visualization, storage, and modeling easier.

What is PCA?

Principal Component Analysis is a linear technique that finds a new set of orthogonal axes (principal components) ordered by the amount of variance they explain. The first principal component points in the direction of greatest variance in the data; the second is orthogonal to the first and captures the next largest remaining variance, and so on.

Why is PCA needed?

  • Visualization of high-dimensional data (project to 2D/3D)
  • Noise reduction and compression
  • Removing multicollinearity before linear models
  • Feature extraction for downstream machine learning

Variance & Covariance

Variance of a feature measures how spread out its values are. Covariance between two features measures how they vary together. The covariance matrix packs all pairwise covariances (and variances on the diagonal) into a single symmetric matrix.

Cov(X) = (1/(n−1)) · XcT Xc

Eigenvalues & Eigenvectors

For a square matrix A, a non-zero vector v and scalar λ satisfying A v = λ v are called an eigenvector and eigenvalue. For the covariance matrix, the eigenvalues are the variances captured by each principal direction, and the eigenvectors are those directions.

Cov · vi = λi · vi

Because Cov is symmetric positive semi-definite, eigenvalues are real and non-negative, and eigenvectors can be chosen orthonormal.

Principal Components & Explained Variance

After sorting eigenvalues λ1 ≥ λ2 ≥ … ≥ λp, the explained variance ratio of component i is λi / Σ λj. The cumulative sum tells you how much total variance is retained by the first k components.

Explained Variance Ratioi = λi / Σj λj

Scree Plot

A bar + line chart of individual and cumulative explained variance. The “elbow” (where the curve flattens) is a practical guide for choosing how many components to keep.

Projection

Once you have the eigenvector matrix W (columns = selected components), the reduced data is obtained by the matrix product:

Xreduced = Xprocessed · W

Covariance PCA vs Standardized PCA

  • Covariance PCA (mean-centering only): sensitive to feature scales. A feature measured in large units can dominate the first components.
  • Standardized / Correlation PCA (z-score each feature): all features contribute on equal footing. Preferable when units differ.

Information Loss

When you keep only the first k components you discard the variance belonging to the remaining components. The percentage lost is 100% − cumulative explained variance of the first k components.

Practical Applications

  • Exploratory data analysis and visualization
  • Image compression and face recognition (eigenfaces)
  • Genomics and spectroscopy
  • Preprocessing step before clustering or regression

Limitations

  • Only linear relationships are captured
  • Sensitive to outliers (they inflate variance)
  • Interpretability of components can be difficult when original features are many
  • Assumes that high variance = importance (not always true for prediction)
